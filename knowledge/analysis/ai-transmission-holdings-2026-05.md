## 二、逐个分析：小米/阿里/金山云能否受益于AI传导？

### 小米 (1810.HK) — AI传导路径最清晰

**AI如何传导到小米:**

```
上游建算力 → 端侧AI芯片成熟 → AI手机/IoT/汽车
                                    ↓
                              小米是终端厂商
                              AI功能 = 产品溢价
                              AI生态 = 用户粘性
```

**具体传导机制:**
1. **AI手机**: 小米15系列搭载端侧AI（实时翻译/图像处理/智能助手）
   → AI功能成为换机理由 → 手机ASP提升
   → 2026年AI手机渗透率从10%→30%，小米是受益者

2. **AIoT**: 米家5亿+设备 → AI驱动的智能家居联动
   → 用户粘性提升 → IoT收入增长

3. **AI汽车**: 自动驾驶/智能座舱依赖AI
   → 小米SU7的智能驾驶功能需要端侧AI芯片
   → 汽车AI功能成为卖点

**传导时间:** 2026年Q3-Q4开始体现（AI手机换机潮）

**小米的问题:**
- 市场还没有price in AI对小米的价值
- 原因：小米被归类为"硬件公司"而非"AI公司"
- 但一旦AI手机销量数据出来，市场会重新定价

**结论: ✅ 逻辑成立。小米是AI传导到to C端的核心标的。**

---

### 阿里巴巴 (09988.HK) — AI传导路径存在但弱

**AI如何传导到阿里:**

```
上游建算力 → 云计算需求爆发 → 阿里云受益
                              → AI电商（推荐/搜索/客服）
                              → AI内容生成（商品图/视频）
```

**传导机制:**
1. **阿里云**: AI训练/推理需要云计算
   → 阿里云是第二大云服务商
   → 但增速已被price in（云业务增长被市场跟踪）

2. **AI电商**: AI推荐→转化率提升→广告收入增长
   → 但这是渐进式的，不是爆发式的

3. **AI内容**: AI生成商品图/视频→降低商家成本
   → 对阿里是降本，不是增收

**阿里的问题:**
- 电商增长2.7%已停滞，AI能改善但不能逆转趋势
- 云业务增长被市场跟踪，不是"预期差"
- ROE 7.5%说明资本效率差，AI投入可能进一步拉低ROE

**结论: ⚠️ 逻辑存在但弱。AI能帮助阿里，但不能改变其增长失速的核心问题。**

---

### 金山云 (3896.HK) — AI传导路径最直接

**AI如何传导到金山云:**

```
上游建算力 → AI模型需要云服务 → 金山云直接受益
                                (金山系生态: WPS+金山云+小米)
```

**传导机制:**
1. **AI算力服务**: 企业提供AI训练/推理的云服务
   → 金山云是金山系的云计算平台
   → 与金山办公(WPS)协同，企业AI需求

2. **小米生态协同**: 小米IoT+AI需要云服务
   → 金山云为小米提供后端支持

**金山云的问题:**
- 仍在亏损(净利-9亿)，现金流-6亿
- 云计算竞争激烈(阿里云/华为云/腾讯云)
- 估值已涨26%，是否还有空间？

**结论: ⚠️ 逻辑最直接，但公司盈利能力差。是"好赛道+差公司"。**
