## 二、逐家分析

### 2.1 铖昌科技 (001270) — ⭐ 最核心标的

**公司简介:**
- 国内微波毫米波相控阵T/R芯片龙头
- 星载领域国产市占率超80%，深度绑定中国星网
- 产品覆盖L波段至W波段，上千种产品
- 应用：星载、机载、舰载、车载、地面相控阵雷达

**核心优势:**
1. **T/R芯片是卫星的"眼睛"** — 相控阵天线的核心元器件，每颗卫星都需要
2. **市占率80%+** — 在星网/千帆星座中几乎不可替代
3. **毛利率72.7%** — 芯片设计公司的典型高毛利，说明有定价权
4. **国产化率90%** — 不受美国制裁影响
5. **星网规划1.3万颗卫星** — 单星芯片价值100-150万元 = 潜在市场130-195亿

**增长逻辑:**
- 2025年营收+91.3%，净利+336.9% — 需求爆发
- 2026Q1净利+50% — 增速在持续
- 分析师预测：2026净利1.73亿，2027净利2.43亿，2028净利3.27亿（CAGR 47%）
- 千帆星座2026年目标648颗，2027年1296颗 — 订单还在加速

**⚠️ 重大风险:**
1. **\*ST状态** — 2024年亏损导致ST，2025年已扭亏，但需要连续盈利才能摘帽
2. **客户集中度高** — 下游主要是国家大型集团下属科研院所
3. **军工订单周期性** — 受军费预算和交付节奏影响
4. **估值未知** — push2 API 502，无法获取当前价格和PE

**类比:**
- 铖昌科技 ≈ 中国的STM（意法半导体）
- STM给Starlink供应相控阵芯片，铖昌给中国星网供应T/R芯片
- STM已交付75亿颗，铖昌还在早期——这意味着铖昌的增长空间更大

### 2.2 臻镭科技 (688270) — 高壁垒但风险更高

**公司简介:**
- 星载射频芯片、ADC/DAC、电源管理芯片
- 解决星载核心器件"卡脖子"问题

**核心优势:**
1. 毛利率75.9% — 比铖昌还高
2. 营收+42.3%，净利+4036%（从亏损到1.14亿）
3. 负债率6.9% — 极健康的资产负债表

**⚠️ 风险:**
1. **\*ST状态** — 比铖昌更危险（ST臻镭）
2. 市占率数据不明
3. 2024年亏损，2025年刚扭亏，持续性待验证

**结论:** 壁垒高但ST风险大，需要等摘帽后再考虑。

### 2.3 上海瀚讯 (300762) — 收入增长但持续亏损

**公司简介:**
- 千帆/G60星座核心供应商
- 星间激光通信载荷、通信分系统
- 2025年已确认1.5亿收入，2026年预计翻倍

**核心问题:**
1. **连续3年亏损** — 2023/2024/2025累计亏损5.32亿
2. 毛利率从63.8%降到33% — 盈利能力恶化
3. 负债率从19.7%升到40% — 杠杆在加大
4. 虽然营收+42%，但亏损也在扩大

**结论:** 收入增长亮眼，但盈利能力太差。需要等扭亏信号。
