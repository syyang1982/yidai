# 关键矿产与稀土元素供应链稀缺性分析报告

**报告日期：2025年7月**
**数据来源：USGS、IEA、Wikipedia、Reuters、CSIS、Gordian Knot Center**

---

## 一、核心发现摘要

当前全球关键矿产供应链面临**结构性脆弱**：中国在稀土、镓、锗、锑、钨、铟等战略元素上占据压倒性主导地位，且已将此优势**武器化**——2023年至2025年间，中国对镓、锗、锑、稀土等实施了多轮出口管制。这不是普通的贸易摩擦，而是**供应链战争**。

---

## 二、关键元素供应链全景图（按稀缺性排序）

### 🔴 极度稀缺（供应瓶颈最严重）

#### 1. 镓（Gallium）- 原子序数31
| 指标 | 数据 |
|------|------|
| **中国产量占比** | **98%**（2024年，USGS数据） |
| **主要用途** | 半导体（GaAs、GaN）、LED、5G、雷达、太阳能电池 |
| **需求驱动** | 5G通信、电动汽车功率器件、AI数据中心散热、国防电子 |
| **价格变化** | 2024年5月：$110-130/kg → 2025年5月：**$687/kg**（涨5倍） |
| **稀缺性评级** | ⭐⭐⭐⭐⭐ 极度稀缺 |

**关键事件：**
- 2014-2016年：中国补贴出口使全球镓价暴跌75%，迫使欧洲唯一初级镓生产商Ingal Stade GmbH（德国）于2016年关闭
- 2023年7月：中国实施镓出口许可证制度
- 2024年12月：中国**全面禁止**对美国出口镓
- 价格飙升5倍，供应链严重中断

**供应风险：** 镓是铝土矿加工的副产品，无法独立开采。中国不仅控制产量，更通过过去十年的补贴策略摧毁了西方的生产能力。

---

#### 2. 重稀土元素（Heavy Rare Earth Elements, HREE）
| 指标 | 数据 |
|------|------|
| **中国加工占比** | **99%**（重稀土分离产能） |
| **关键元素** | 钆(Gd)、铽(Tb)、镝(Dy)、钬(Ho)、铒(Er)、铥(Tm)、镱(Yb)、镥(Lu)、钇(Y) |
| **主要用途** | 永磁体（电动汽车电机、风力发电机）、国防（导弹制导、战斗机发动机） |
| **预测** | 2030年西方对中国重稀土依赖度：**91%**（2024年为99%） |
| **稀缺性评级** | ⭐⭐⭐⭐⭐ 极度稀缺 |

**关键数据：**
- IEA估计：中国占全球稀土分离和精炼产能的**91%**
- 中国占烧结永磁体生产的**94%**
- 中国持有全球稀土相关专利的**81%**（2014-2024年22,040个专利族）
- 2025年产量：270,000吨（稀土氧化物当量），储量：4400万吨

**三重锁定效应（The Diplomat分析）：**
1. **资源锁定**：中国离子型粘土矿是全球最经济的重稀土来源，西方硬岩型开采成本高数倍
2. **技术锁定**：中国在溶剂萃取工艺上积累了数十年工业级经验，并通过出口管制限制技术外流
3. **生态锁定**：中国建立了从采矿到磁铁生产的完整产业链，国内EV和风电产业足以支撑规模经济

---

#### 3. 锑（Antimony）- 原子序数51
| 指标 | 数据 |
|------|------|
| **中国产量占比** | **54.5%**（2022年USGS） |
| **俄罗斯** | 18.2% |
| **塔吉克斯坦** | 15.5% |
| **主要用途** | 弹药、阻燃剂、铅酸电池、红外探测器 |
| **稀缺性评级** | ⭐⭐⭐⭐⭐ 极度稀缺 |

**关键风险：**
- 中国湖南锡矿山是全球最大锑矿
- 中国产量因环保法规收紧而持续下降
- 中国剩余经济储量正在**快速枯竭**
- 缅甸（另一重要产地）因政治动荡面临供应中断
- 2024年12月：中国**禁止**对美国出口锑
- **军事意义重大**：锑是弹药和穿甲弹的关键成分

---

#### 4. 锗（Germanium）- 原子序数32
| 指标 | 数据 |
|------|------|
| **中国产量占比** | **60%**（精炼产量） |
| **主要用途** | 光纤通信、红外光学（夜视仪）、太阳能电池、半导体 |
| **军事应用** | 红外制导系统、热成像、卫星光学 |
| **稀缺性评级** | ⭐⭐⭐⭐ 高度稀缺 |

**关键事件：**
- 2023年7月：中国实施锗出口许可证制度
- 2024年12月：中国**全面禁止**对美国出口锗
- 锗是闪锌矿（锌矿）的副产品，供应受锌矿开采量限制
- 已知锌矿中含可提取锗约10,000吨，煤中含112,000吨

### 🟠 高度稀缺

#### 5. 钨（Tungsten）- 原子序数74
| 指标 | 数据 |
|------|------|
| **中国储量占比** | **56%**（180万吨/全球320万吨） |
| **中国产量占比** | ~80%（2017年：79,000吨/全球约100,000吨） |
| **主要用途** | 硬质合金（切削工具）、穿甲弹、高温合金、照明 |
| **稀缺性评级** | ⭐⭐⭐⭐ 高度稀缺 |

**关键风险：**
- 钨的硬度和高密度使其成为军事应用的核心材料（穿甲弹）
- 二战期间钨就是战略争夺焦点（葡萄牙的钨矿）
- 中国政府严格监管供应，打击非法采矿和过度污染
- 越南产量增长但远不及中国

---

#### 6. 铟（Indium）- 原子序数49
| 指标 | 数据 |
|------|------|
| **中国产量占比** | ~44%（2016年：290吨/全球655吨） |
| **韩国** | 30%（195吨） |
| **主要用途** | ITO靶材（LCD/OLED显示屏）、半导体、LED |
| **稀缺性评级** | ⭐⭐⭐⭐ 高度稀缺 |

**关键特征：**
- 铟是锌矿开采的副产品，无法独立开采
- 全球50%消费用于LCD面板生产
- 回收率极低（<1%）
- 智能手机、平板、电视屏幕都依赖ITO（氧化铟锡）

---

#### 7. 铂族金属（Platinum Group Metals, PGMs）
| 指标 | 数据 |
|------|------|
| **南非产量占比** | **77%**（铂金） |
| **俄罗斯** | 13% |
| **关键元素** | 铂(Pt)、钯(Pd)、铑(Rh)、钌(Ru)、铱(Ir)、锇(Os) |
| **主要用途** | 催化转化器、氢燃料电池、电子器件、化工催化剂 |
| **稀缺性评级** | ⭐⭐⭐⭐ 高度稀缺 |

**关键特征：**
- 铂在地壳中浓度仅0.005ppm，极度稀有
- 南非Bushveld杂岩体含全球约75%已知铂储量
- 氢经济（氢燃料电池）将大幅增加铂需求
- 南非电力危机和矿业劳资纠纷威胁供应

### 🟡 中度稀缺

#### 8. 稀土元素（轻稀土，LREE）
| 指标 | 数据 |
|------|------|
| **中国加工占比** | 91%（分离和精炼） |
| **关键元素** | 镧(La)、铈(Ce)、镨(Pr)、钕(Nd)、钐(Sm)、铕(Eu) |
| **主要用途** | 永磁体（钕铁硼）、催化剂、抛光粉、电池 |
| **稀缺性评级** | ⭐⭐⭐ 中度稀缺（轻稀土储量较分散，但加工集中在中国） |

**投资视角：** 轻稀土储量在澳大利亚、美国、加拿大等地较丰富，但加工能力严重不足。Lynas（澳大利亚）是最大的非中国稀土生产商，但仍需将部分中间产品运至中国加工。

---

#### 9. 锂（Lithium）- 原子序数3
| 指标 | 数据 |
|------|------|
| **主要产地** | 澳大利亚（矿石）、智利（盐湖）、中国、阿根廷 |
| **中国加工占比** | ~65%（精炼和电池材料） |
| **主要用途** | 锂离子电池（EV、储能）、陶瓷、玻璃 |
| **稀缺性评级** | ⭐⭐⭐ 中度稀缺（储量充足但精炼集中在中国） |

**关键特征：**
- 锂储量相对充足（智利、澳大利亚、阿根廷"锂三角"）
- 瓶颈在于精炼和电池材料加工——中国控制约65%
- 2022-2023年锂价暴跌（从峰值下跌>80%），但长期需求增长确定
- 钠离子电池技术可能部分替代锂需求

---

#### 10. 钴（Cobalt）- 原子序数27
| 指标 | 数据 |
|------|------|
| **刚果（金）产量占比** | **>80%**（2024年：超30万吨中占24万+吨） |
| **中国精炼占比** | ~70%（精炼钴） |
| **主要用途** | 锂离子电池正极材料、高温合金、磁性材料 |
| **稀缺性评级** | ⭐⭐⭐ 中度稀缺（产地极度集中但储量尚可） |

**关键风险：**
- 刚果（金）政治不稳定、童工问题、 artisanal mining
- 中国企业在刚果（金）大量收购钴矿
- 无钴电池技术（LFP、高镍低钴）正在减少单位用量

## 三、中国出口管制武器化时间线

| 时间 | 措施 | 影响 |
|------|------|------|
| 2010年 | 对日本暂停稀土出口（中日东海争端） | 稀土价格飙升，全球警觉 |
| 2014-2016年 | 补贴镓出口，压低全球价格75% | 欧洲唯一镓生产商关闭 |
| 2023年7月 | 镓、锗出口许可证制度 | 半导体供应链震动 |
| 2023年 | 禁止稀土加工技术出口 | 阻止西方建立独立产能 |
| 2024年12月 | 禁止对美出口镓、锗、锑 | 供应链严重中断 |
| 2025年 | 限制对美重稀土出口 | 国防供应链告急 |
| 2025年4月 | 对稀土实施出口管制（回应特朗普关税） | 全球稀土价格波动 |
| 2025年10月 | 扩大稀土出口管制（聚焦国防和芯片） | 双重用途物品需审批 |
| 2026年 | 引入稀土行业实时管控和处罚机制 | 全面管控升级 |

## 四、需求驱动因素分析

### 1. 电动汽车（EV）
- **钕铁硼永磁体**：每辆EV电机需要约1-2kg稀土永磁体
- **锂**：每辆EV电池需要约8-12kg碳酸锂当量
- **钴**：三元锂电池需要钴（LFP正在替代）
- **镓/氮化镓**：EV功率电子器件

### 2. 半导体与AI
- **镓**：GaAs/GaN用于5G基站、AI芯片功率管理
- **锗**：光纤通信基础设施
- **铟**：先进显示屏（OLED）
- **稀土**：抛光粉（芯片制造）

### 3. 国防与军事
- **稀土**：导弹制导系统、战斗机发动机永磁体、声呐
- **锑**：弹药、穿甲弹
- **钨**：穿甲弹、高温合金
- **锗**：红外夜视、热成像
- **镓**：雷达系统、电子战

**关键洞察：** 美国国防部的稀土消耗不到全球需求的0.1%（Gordian Knot Center 2025报告："我们每月生产12架战斗机，而特斯拉每天生产近5000辆电动汽车"）。商业需求——而非军事需求——决定世界市场价格，国防供应链韧性取决于更广泛的工业条件。

### 4. 绿色能源
- **稀土**：风力发电机永磁体（每台海上风机需要数百kg稀土）
- **铂族金属**：氢燃料电池催化剂
- **硅/银**：太阳能电池
- **锂**：电网储能

### 5. AI与数据中心
- **镓**：高效电源管理（GaN功率器件）
- **铜**：数据中心布线和电力基础设施
- **稀土**：硬盘驱动器永磁体

## 六、西方应对策略与进展

### 美国
- **《通胀削减法案》（IRA）**：推动国内关键矿产供应链
- **国防生产法**：资助稀土加工设施建设
- **Mountain Pass矿**（加州）：重启运营，但仍需将精矿运至中国加工
- **战略储备**：正在增加关键矿产战略储备

### 欧盟
- **《关键原材料法案》（CRMA）**：2024年生效，目标到2030年实现10%开采、40%加工、25%回收
- 呼应CSIS建议：识别并集中投资稀土加工枢纽

### 澳大利亚
- **Lynas稀土**：全球最大非中国稀土生产商，在澳大利亚采矿、马来西亚加工
- **关键矿产战略2023-2030**：政府支持开发国内供应链

### 日本
- 多元化供应来源，与澳大利亚、加拿大合作
- 投资稀土回收技术

## 七、投资启示

### 1. 稀缺性溢价将持续扩大
中国出口管制已从"威胁"变为"现实"。镓价5倍涨幅证明了供应链风险的真实定价影响。

### 2. 关注"非中国"稀土/关键矿产生产商
- **Lynas Rare Earths (ASX: LYC)**：最大非中国稀土生产商
- **MP Materials (NYSE: MP)**：Mountain Pass稀土矿运营商
- **Arafura Resources (ASX: ARU)**：澳大利亚稀土开发
- **Albemarle (NYSE: ALB)**：全球最大锂生产商之一

### 3. 关注替代技术
- **无钴电池**（LFP）减少钴依赖
- **无稀土电机**（开关磁阻电机、电励磁同步电机）
- **钠离子电池**减少锂依赖
- **硅基替代**减少铟（ITO）依赖

### 4. 回收与城市矿山
- 日本在稀土回收方面领先
- 电子废弃物中的关键矿产回收将成为重要供应来源

### 5. 地缘政治风险溢价
- 拥有"非中国"供应链的公司将享有估值溢价
- 关键矿产ETF和实物矿产基金可作为对冲工具

## 八、结论

全球关键矿产供应链正处于**结构性重构**的前夜。中国在过去40年建立的主导地位不是偶然的——它是系统性产业政策、补贴、技术积累和规模经济的结果。西方要建立替代供应链，需要**10-15年**和**数千亿美元**的投资。

**对投资者的核心信息：**
1. 关键矿产的"中国风险"已被**严重低估**
2. 稀缺性溢价将在未来5-10年持续扩大
3. 非中国供应链的建设将创造巨大的投资机会
4. 替代技术和回收将是长期解决方案，但短期内无法改变供需格局
5. 关注中国出口管制的每一次升级——它们是投资信号
