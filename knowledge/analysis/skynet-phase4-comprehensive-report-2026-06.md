### 3.2 与现有持仓的关系

用户现有13个持仓（小米61%为核心），天网组合是**增量配置**，不替代现有持仓。

| 现有持仓 | 与天网关联 | 建议 |
|---------|----------|------|
| 小米 (01810) | 弱（AIoT部分相关） | 保持核心 |
| 金山云 (KC) | 中（AI算力） | 可减少，用NVDA替代部分暴露 |
| 顺丰 (002352) | 无 | 不变 |
| 蜜雪 (2097.HK) | 无 | 不变 |
| 其他9个 | 弱 | 不变 |

**关键建议:** 天网投资资金应来自新增资金或减仓乐信(LX)的释放资金，不应减持小米核心仓位。

## 六、风险监控

### 6.1 需要持续监控的风险信号

| 信号 | 影响 | 应对 |
|------|------|------|
| SpaceX星链订户增长放缓 | 通信层估值下调 | 减仓HXL/MTRN |
| 中美关系急剧恶化 | 中国标的暴跌 | 减仓A股标的 |
| 美国国防预算削减 | 执行层承压 | 减仓AVAV/KTOS |
| 铖昌科技连续亏损 | 退市风险 | 清仓 |
| AI泡沫破裂 | 全体承压 | 减仓NVDA/PLTR |
| 铍/碳纤维价格暴跌 | MTRN/HXL利润压缩 | 评估周期位置 |

### 6.2 组合再平衡规则

- 每季度review一次六维评分
- 单标的仓位上限15%（核心持仓可到25%）
- 天网组合总仓位不超过总组合的30%
- 如果某个标的涨超目标仓位20%，减仓至目标
