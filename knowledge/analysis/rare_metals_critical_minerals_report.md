## 一、A股市场（中国大陆）

### 1. 北方稀土（600111.SH）⭐⭐⭐⭐⭐

| 指标 | 数据 |
|------|------|
| **市值** | 约 1,200-1,500亿元人民币 |
| **矿种** | 稀土（轻稀土为主） |
| **控股股东** | 包钢集团（全球最大轻稀土矿——白云鄂博矿） |

**核心优势：**
- **资源储量**：依托白云鄂博矿，稀土储量全球第一，占中国稀土开采配额的50%以上
- **产业链完整**：从稀土精矿→稀土氧化物→稀土金属→磁性材料，全产业链覆盖
- **战略地位**：中国稀土行业绝对龙头，国家稀土整合的核心平台
- **财务表现**：2024年营收约300-350亿元，受稀土价格周期影响波动较大；2021-2022年高点后价格回调，2025年随新能源需求回暖有望企稳回升

**投资逻辑**：中国稀土出口管控政策的核心受益标的，供给端收紧+新能源/军工需求增长的双重驱动。

---

### 2. 赣锋锂业（002460.SZ）⭐⭐⭐⭐⭐

| 指标 | 数据 |
|------|------|
| **市值** | 约 800-1,200亿元人民币 |
| **矿种** | 锂（全球最大锂矿公司之一） |
| **全球布局** | 澳洲、阿根廷、墨西哥、非洲等 |

**核心优势：**
- **资源储量**：全球锂资源权益储量超过4,000万吨LCE，覆盖锂辉石、盐湖卤水、锂云母等多种类型
- **产能规模**：碳酸锂+氢氧化锂年产能超10万吨，规划扩产至20万吨+
- **技术路线**：固态电池技术领先，第三代固态电池已进入中试阶段
- **财务表现**：2024年受锂价大幅下跌影响利润承压（碳酸锂从60万/吨跌至7-8万/吨），2025年锂价筑底企稳，长期看电动车渗透率提升支撑需求

**投资逻辑**：锂资源全球龙头，锂价周期底部的弹性标的，同时布局固态电池打开长期成长空间。

---

### 3. 华友钴业（603799.SH）⭐⭐⭐⭐

| 指标 | 数据 |
|------|------|
| **市值** | 约 500-700亿元人民币 |
| **矿种** | 钴、镍、锂 |
| **核心布局** | 刚果（金）钴矿 + 印尼镍项目 |

**核心优势：**
- **钴资源**：在刚果（金）拥有多个钴铜矿项目，钴资源储量位居全球前列
- **镍布局**：印尼华越镍钴项目（6万吨镍），切入三元正极材料上游
- **一体化**：从矿产→前驱体→正极材料的一体化布局，绑定LG、三星SDI等国际大客户
- **财务表现**：2024年镍钴价格低迷拖累业绩，但前驱体出货量持续增长，2025年有望受益于新能源需求恢复

**投资逻辑**：钴镍锂多金属布局的新能源材料龙头，产业链一体化提升抗周期能力。

---

**A股其他关注标的**：
- **厦门钨业（600549）**：钨+稀土双主业，硬质合金龙头
- **盛和资源（600392）**：稀土资源整合平台，海外矿产布局
- **中国铝业（601600）**：镓、锗副产品生产龙头，关键矿物出口管控受益

### 2. 天齐锂业（09696.HK）⭐⭐⭐⭐⭐

| 指标 | 数据 |
|------|------|
| **市值** | 约 400-600亿港元 |

| **核心资产** | 澳洲Greenbushes锂矿（全球最大硬岩锂矿）+ 智利SQM股权 |

**投资逻辑**：拥有全球最优质锂资源的公司之一，锂价反转时弹性极大。

## 三、美股市场（美国）

### 1. MP Materials（MP）⭐⭐⭐⭐⭐

| 指标 | 数据 |
|------|------|
| **市值** | 约 30-50亿美元 |
| **矿种** | 稀土 |
| **核心资产** | Mountain Pass稀土矿（美国唯一运营中的稀土矿） |

**核心优势：**
- **美国稀土独苗**：Mountain Pass是美国唯一在产稀土矿，战略地位极高
- **政策红利**：美国国防部、能源部大力资助，IRA法案关键矿产补贴受益
- **垂直整合**：从矿山开采→分离→金属/合金→磁体，正在建设完整供应链
- **产能扩张**：2025年分离产能投产，目标年产6万吨+稀土氧化物
- **财务表现**：2024年因稀土价格下跌收入承压，但政府补贴和长期合同提供安全垫

**投资逻辑**：美国重建稀土供应链的唯一本土标的，地缘政治+政策支持的确定性最强。

---

### 2. Albemarle（ALB）⭐⭐⭐⭐

| 指标 | 数据 |
|------|------|
| **市值** | 约 80-120亿美元 |
| **矿种** | 锂 |
| **全球布局** | 智利、澳洲、中国 |

**核心优势：**
- **全球最大锂生产商**：年产锂约10万吨LCE，全球最大
- **资源储备**：智利盐湖+澳洲锂辉石+中国加工，多元化资源布局
- **技术领先**：锂提取技术持续优化，Direct Lithium Extraction（DLE）技术布局
- **长期合同**：与特斯拉、福特、GM等签订多年长协，锁定量价
- **财务表现**：2024年锂价暴跌导致利润大幅下滑，2025年产能扩张完成后有望随价格回暖改善

**投资逻辑**：全球锂业龙头，长期合同提供下行保护，锂价反转时弹性大。

### 3. Freeport-McMoRan（FCX）⭐⭐⭐⭐

| 指标 | 数据 |
|------|------|
| **市值** | 约 550-700亿美元 |
| **矿种** | 铜、钼、金 |
| **核心资产** | Grasberg铜金矿（全球最大铜矿之一） |

- **关键矿物**：铜是电气化和新能源的核心金属，需求增长确定性最强
- **副产品**：黄金、钼等副产品提供额外收入
- **财务强劲**：铜价高位运行（2024-2025年铜价创新高），自由现金流充沛，分红慷慨

**投资逻辑**：铜是"新时代的石油"，电气化+AI数据中心驱动铜需求长期增长，FCX是最大受益者之一。

## 六、投资策略建议

### 短期（6-12个月）
1. **锂板块触底反弹**：碳酸锂价格已跌至成本线附近（7-8万元/吨），供给端减产+需求增长有望推动价格回升。首选：赣锋锂业、天齐锂业、Pilbara Minerals
2. **稀土政策催化**：中国稀土出口管控持续收紧，稀土价格有望企稳。首选：北方稀土、Lynas

### 中期（1-3年）
3. **铜的超级周期**：电气化+AI驱动铜需求长期增长，供给端新矿开发周期长（5-10年）。首选：Freeport-McMoRan
4. **西方稀土供应链重建**：MP Materials和Lynas受益于地缘脱钩和政府补贴

### 长期（3-5年）
5. **固态电池革命**：赣锋锂业固态电池技术领先，可能改变锂的消费结构
6. **关键矿物安全**：镓、锗、锑、钨等战略小金属受出口管控影响价格可能持续走高

### 风险提示
- ⚠️ 大宗商品价格周期性波动风险
- ⚠️ 地缘政治风险（中美关系、出口管控政策变化）
- ⚠️ 技术替代风险（钠电池替代锂、无稀土电机等）
- ⚠️ 环保和社区风险（矿业项目审批和运营风险）
