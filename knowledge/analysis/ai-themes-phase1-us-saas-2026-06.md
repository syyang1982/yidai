## ServiceNow (NOW)
- 主营业务: 企业级数字工作流云平台（IT、HR、客服、安全等），正在转型为"AI控制塔"
- AI相关性: ⭐⭐⭐⭐⭐ — AI Agent平台战略，目标2030年$300亿营收，与IBM/Nvidia深度合作
- 护城河: 企业ITSM/工作流领域的事实标准，深度嵌入客户核心运维流程，迁移成本极高
- 客户锁定: 极高 — 大型企业IT工作流全面依赖，平均合同周期3-5年，切换需重写数千个自动化流程
- PE(TTM)/Forward PE: 60.32 / 23.37
- 市值: $984.7亿
- 营收增长/净利增长: +21.7% / +14.2%
- ROE/股息率: 未披露 / 无分红
- 52周区间: $81.24 - $211.48
- 分析师共识/目标价: Strong Buy (48人) / $141.98 (+48.7%)
- 核心风险: 估值仍偏高(PE 60x)，AI投入回报期不确定，近期数据安全漏洞事件
- 估值判断: Forward PE 23x在成长型SaaS中合理，考虑20%+增长和AI催化，估值可接受

## Veeva Systems (VEEV)
- 主营业务: 生命科学行业云软件（CRM、临床、质量管理、药物安全），行业唯一全栈解决方案
- AI相关性: ⭐⭐⭐⭐ — Falcon AI平台、Agentic CRM，但AI更多是产品增强而非核心驱动
- 护城河: 生命科学行业唯一合规级CRM，FDA/GxP验证流程使其几乎不可能被替代
- 客户锁定: 极高 — 药企合规系统切换需FDA重新验证，通常耗时2-3年，风险巨大
- PE(TTM)/Forward PE: 27.46 / 16.76
- 市值: $251.5亿
- 营收增长/净利增长: +16.2% / +20.6%
- ROE/股息率: 未披露 / 无分红
- 52周区间: $148.05 - $310.50
- 分析师共识/目标价: Buy (29人) / $245.48 (+58.5%)
- 核心风险: 增速放缓至16%，生命科学行业并购影响客户数量，Goldman给予Sell评级
- 估值判断: Forward PE仅16.76x，对16%增长的垄断型公司非常便宜，当前股价处于52周低位附近

## Guidewire Software (GWRE)
- 主营业务: 财产与意外险(P&C)核心系统（保单、理赔、计费），保险行业IT现代化基石
- AI相关性: ⭐⭐⭐⭐ — ProNavigator AI助手嵌入核心应用，AI驱动的保险工作流革新
- 护城河: P&C保险核心系统市占率第一，云迁移锁定客户10年+周期，监管合规要求极高
- 客户锁定: 极高 — 保险核心系统替换周期5-10年，涉及数百万保单数据迁移，成本数亿美元
- PE(TTM)/Forward PE: 59.88 / 28.86
- 市值: $92.6亿
- 营收增长/净利增长: +24.9% / +361.8%（低基数效应）
- ROE/股息率: 未披露 / 无分红
- 52周区间: $111.08 - $272.60（当前接近52周低点）
- 分析师共识/目标价: Buy (15人) / $207.00 (+86.2%)
- 核心风险: 云转型执行风险，客户迁移节奏不确定，近期股价大幅回调(-59%)
- 估值判断: 当前处于52周最低位，Forward PE 28.86x对24.9%增长偏贵，但云转型加速期利润弹性大

## Toast Inc (TOST)
- 主营业务: 餐饮行业全栈SaaS（POS、在线点餐、支付、工资、库存、AI分析）
- AI相关性: ⭐⭐⭐⭐ — Toast IQ对话式AI，AI驱动的运营优化和利润率保护
- 护城河: 餐饮全栈软硬件一体化，POS+支付+运营数据闭环，但行业竞争激烈
- 客户锁定: 中高 — 硬件+软件+支付一体化绑定，但餐饮业客户基数大、单体规模小，切换成本相对较低
- PE(TTM)/Forward PE: 36.66 / 17.29
- 市值: $141.5亿
- 营收增长/净利增长: +23.4% / +160.8%（扭亏为盈阶段）
- ROE/股息率: 未披露 / 无分红
- 52周区间: $22.26 - $49.66
- 分析师共识/目标价: Buy (29人) / $33.88 (+38.8%)
- 核心风险: DoorDash竞争威胁，Beta 1.76波动性极高，餐饮行业周期敏感
- 估值判断: Forward PE 17.29x合理，但竞争加剧和高Beta是减分项，适合看好餐饮数字化的投资者
