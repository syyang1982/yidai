### ⚠ 修正一条 memory 里的旧数据

我 memory 里存的是「中国铝业 5 年 PB: 0.63x(2022底)-1.32x(2025)，均值 ~1.07x」。

**用不复权价 ÷ 同期 BPS 重算的结果完全不同**：

| 时点 | 收盘(不复权) | BPS | **PB** |
|---|---|---|---|
| 2022-12 | 4.47 | 3.05 | **1.464** |
| 2025-03 | 7.46 | 4.21 | 1.772 |
| 2025-12 | 12.22 | 4.37 | 2.798 |

**memory 里的 0.63 应是前复权价口径造成的错配**——用前复权价（被人为调低的历史价）除以**当时的** BPS，两者不匹配。**正确口径是不复权价 ÷ 同期 BPS**，两者都是当时的真实值，自洽。

→ 已修正。**中铝 5 年 PB 均值是 1.88，不是 1.07；击球区（μ-2σ）是 1.12，不是更低。**

## 二、中钨高新 000657 —— 炒作后回落，但仍贵

**现价 ¥44.19**（昨收 46.67，跌 -5.31%）

### 估值

| 统计 | 值 |
|---|---|
| **当前 PB** | **8.927** |
| **20 季度分位** | **90%**（比 5 年里 90% 的时间都贵） |
| PB 区间 | 1.650（2024-12）~ **19.336（2026-06）** |
| μ-2σ | **-4.20 ⚠ 负数，弃用** |
| PE-TTM | **35.82**（最高） |
| ROE-TTM | 24.92%（不低） |
| 市值 | ¥1,007 亿 |
| 52 周高 | **95.72（2026-06）**，距高 **-53.8%** |

### PB 的轨迹说明了一切

```
2021-09  2.459
2024-12  1.650   ← 谷底
2025-06  2.835
2025-12  6.495
2026-03 10.175
2026-06 19.336   ← 峰值
现在      8.927
```

**PB 从 2024 年底的 1.65 涨到 2026 年 6 月的 19.34（+1,072%），现在回落 54% 到 8.93。**

**这是"柿竹园注入预期 + 钨出口管制"双重题材炒作的结果**，不是盈利驱动。

### ⚠ 一个必须注意的异常：BPS 在跳动，没有趋势

```
4.47 → 5.11 → 4.05 → 5.10 → 4.18 → 5.58 → 4.58 → 4.18 → 4.33 → 4.27 → 4.69 → 4.95
```

**BPS 在 4.05-5.58 之间无规律跳动，5 年净增仅 +11%。** 这与 ROE-TTM 24.92% 不匹配——高 ROE 应该带来净资产的复利增长。

**可能原因**：重大资产重组（柿竹园托管/注入）导致的会计口径调整、股本变动、或少数股东权益重分类。**我没有查清，这是关键缺口。**

### 财务

**2026H1：营收 163.8 亿，归母 20.76 亿，半年 ROE 19.29%**——业绩确实在改善。

## 三、云南锗业 002428 —— 纯概念炒作，建议直接排除

**现价 ¥80.34**（昨收 82.16，跌 -2.22%）

### 估值——极端

| 统计 | 值 |
|---|---|
| **当前 PB** | **34.187** |
| **20 季度分位** | **95%** |
| PB 区间 | 4.313（2022-09）~ **51.140（2026-06）** |
| **PE-TTM** | **726.09** ⚠ |
| ROE-TTM | **4.71%** |
| 市值 | **¥525 亿** |
| **BPS** | **2.25 → 2.35（5 年仅 +4.4%）** |

### 规模和估值完全脱节

- **2026H1 营收仅 7.3 亿，归母 0.74 亿，半年 ROE 4.96%**
- **市值 525 亿 vs 半年营收 7.3 亿** → 年化 PS **约 36 倍**
- **PE-TTM 726 倍**

**BPS 五年只增长 4.4%**——净资产几乎零增长，说明公司赚的钱基本没有留存为股东权益。

**PB 从 4.31（2022-09）涨到 51.14（2026-06），+1,086%**，现在回落到 34.19。

### 判断

**这完全违反你"回避 PE>100 概念股"的原则。** 锗价四年涨 245% 是真的，但**云南锗业这家公司没有把锗价上涨转化为股东价值**——ROE 只有 4.71%，BPS 五年不增长。

**锗的"奇货"属性和云南锗业的投资价值是两回事。** 建议归为 **❌ 暂不考虑**。
