# 天网投资框架 · 第二层：执行层分析报告

> **报告日期：** 2026年6月17日
> **分析主题：** 无人机/国防执行层 — "Starlink + Drones + AI = 未来战争体系"
> **覆盖标的：** 美股3只 + A股2只

---

## 一、核心逻辑

天网体系的执行层是**无人机蜂群 + 精确打击 + 有人/无人协同**。Starlink提供通信底座，AI提供决策大脑，而执行层就是**把弹药送到目标的物理载体**。

```
Starlink（通信层）→ AI（决策层）→ 无人机/导弹（执行层）
                         ↑ 你在这里分析
```

关键趋势：
- 俄乌战争证明：小型无人机已改变战场格局，成本效益比碾压传统武器
- 忠诚僚机（Loyal Wingman）概念兴起：AI控制的无人战斗机配合有人机
- 中国CH-7隐身无人机2025年12月首飞，标志中国无人机进入隐身时代
- 美国正在大规模扩产弹药和无人机（AVAV产能提升500%）

## 六、核心观点总结

1. **执行层是天网体系中确定性最高的投资方向** — 无人机已从概念变为战场现实，俄乌战争是铁证
2. **美股优于A股** — 美国无人机公司在实战订单、技术迭代、资本市场反馈上远超中国同行
3. **LHX是最佳风险收益比标的** — 估值合理+增长稳健+系统集成能力
4. **AVAV是最佳弹性标的** — Switchblade实战验证+产能500%爆发，但需等盈利
5. **中国标的需耐心** — 航天彩虹CH-7和中无人机翼龙系列方向正确，但盈利能力不稳定，建议观察2026年业绩再决定
6. **KTOS是高风险投机标的** — Valkyrie项目改变游戏规则，但147x Forward PE意味着任何利空都会暴跌
