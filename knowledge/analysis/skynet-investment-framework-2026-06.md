## 一、天网架构总览

```
                    ┌─────────────────────────────────┐
                    │         天网 (Sky Net)           │
                    │    全球感知 + 全球打击 + 全球通信  │
                    └────────┬────────┬────────┬───────┘
                             │        │        │
               ┌─────────────▼──┐ ┌───▼──────┐ ┌▼──────────────┐
               │  通信层         │ │ 执行层    │ │ 智能层         │
               │  (Communication)│ │(Execution)│ │(Intelligence) │
               │  卫星星座/频谱  │ │ 无人机群  │ │ AI/算力       │
               │  地面终端/天线  │ │ 无人车辆  │ │ 目标识别      │
               │  芯片/放大器    │ │ 机器人    │ │ 自主决策      │
               └────────────────┘ └──────────┘ └───────────────┘
```

### 核心逻辑
- **通信层**是基础设施：没有星链，无人机群是瞎子
- **执行层**是物理力量：没有无人机，星链只是WiFi
- **智能层**是大脑：没有AI，无人机只是靶子
- 三者缺一不可，构成完整的"感知-决策-打击"闭环

## 三、研究方法论

### 3.1 六维分析框架

对每家候选公司，从六个维度打分（1-5分）：

```
┌──────────────────────────────────────────────────────────────┐
│                    六维分析框架                                │
├──────────────┬──────────────────────────────────────────────┤
│ 维度         │ 评估标准                                      │
├──────────────┼──────────────────────────────────────────────┤
│ 1. 话语权     │ 在供应链中的议价能力                          │
│  (Power)     │ - 是否是唯一供应商？                          │
│              │ - 客户集中度高低？                            │
│              │ - 能否涨价转嫁成本？                          │
├──────────────┼──────────────────────────────────────────────┤
│ 2. 稀缺性     │ 资源/技术的不可替代程度                       │
│  (Scarcity)  │ - 物理稀缺（频谱、铍金属）                    │
│              │ - 认证壁垒（宇航级、军工）                    │
│              │ - 专利/工艺壁垒                               │
├──────────────┼──────────────────────────────────────────────┤
│ 3. 技术壁垒   │ 技术领先程度和追赶难度                        │
│  (Tech Moat) │ - 研发投入占比                                │
│              │ - 技术代差（几年领先？）                       │
│              │ - 生态锁定（CUDA、认证）                      │
├──────────────┼──────────────────────────────────────────────┤
│ 4. 财务价值   │ 当前估值是否合理                              │
│  (Value)     │ - PE/PS vs 行业平均                           │
│              │ - ROE/ROIC 资本效率                            │
│              │ - 自由现金流质量                               │
├──────────────┼──────────────────────────────────────────────┤
│ 5. 成长性     │ 未来增长空间和速度                            │
│  (Growth)    │ - 营收CAGR（3年/5年）                         │
│              │ - TAM（可寻址市场）大小                        │
│              │ - 增速趋势（加速/稳定/减速）                   │
├──────────────┼──────────────────────────────────────────────┤
│ 6. 战略匹配   │ 与"天网"框架的契合度                          │
│  (Strategic) │ - 是否在通信/执行/智能层的核心位置？           │
│              │ - 是否同时服务中美两个阵营？                   │
│              │ - 地缘政治风险/收益                           │
└──────────────┴──────────────────────────────────────────────┘
```

### 3.2 评分矩阵

```
评分标准:
5 = 极强（行业前三/垄断/不可替代）
4 = 强（有明显优势）
3 = 中等（有竞争力但非领先）
2 = 弱（存在明显短板）
1 = 极弱（严重问题）

总分 = 六维加权（可调整权重）
- 长线布局权重: 稀缺性×1.5 + 战略匹配×1.5 + 成长性×1.2 + 话语权×1.0 + 技术壁垒×1.0 + 财务价值×0.8
```

每家公司不是孤立分析，而是放在产业链内横向对比：

├──────────┼──────┼──────┼──────┼──────┼──────┼──────┤
│ STM      │  ?   │  ?   │  ?   │  ?   │  ?   │  ?   │

### 3.4 情景分析

对核心标的做三种情景分析：

```
乐观情景: 天网逻辑全面兑现 → 营收/利润增速 → 目标估值
基准情景: 部分兑现（商业成功，军事有限）→ 合理估值
悲观情景: 技术失败/地缘冲突升级 → 最差情况 → 止损位
```

## 四、Out-of-Box问题 #1: 直接买SpaceX？

### 论点分析

| 维度 | 买SpaceX | 买供应链 |
|------|---------|---------|
| 弹性 | 高（直接受益于Starlink增长） | 中（传导有延迟） |
| 估值风险 | 极高（PS 100x） | 中（各公司估值不同） |
| 分散化 | 单一标的 | 多标的分散 |
| 流动性 | 好（IPO后） | 好（已有上市标的） |
| 下行保护 | 无（估值崩=全亏） | 有（供应链公司有其他业务） |
| 地缘风险 | 低（纯美股） | 中（涉及中国标的需注意） |

### 结论

**不建议直接买SpaceX，理由：**

1. **PS 100x = 你在为马斯克的梦想买单**。即使Starlink成功，股价已经price in了大部分预期。2018年买特斯拉是因为PS只有10x，现在SpaceX的起点完全不同。

2. **供应链有"免费期权"**。如果SpaceX成功，供应链跟着涨；如果SpaceX失败，供应链公司（HXL、CRS）还有航空/国防业务兜底。SpaceX没有这个安全网。

3. **12月锁定期是风险**。大量员工/机构股票解禁，可能引发20-30%回调。如果要买，至少等锁定期后。

4. **唯一买SpaceX的理由：** 你认为SpaceX会成为万亿美元公司（当前$1.77T已经是），且增长速度远超供应链公司。这需要对马斯克有极强信仰。

**建议：** 如果真的想押SpaceX，用HXL+MTRN+STM的组合代替，既享受供应链增长，又有下行保护。

## 五、Out-of-Box问题 #2: 中国无人机供应链

### 行业背景

- 乌克兰战争验证了无人机群+AI的不对称战争能力
- 美国正在推动国产无人机替代中国组件（五角大楼政策）
- 中国无人机产业链成熟，军贸出口活跃（彩虹/翼龙系列）
- 低空经济政策推动民用无人机市场爆发

### 核心标的

| 公司 | 代码 | 角色 | 核心产品 | 优势 | 风险 |
|------|------|------|---------|------|------|
| 航天彩虹 | 002389 | 军用无人机第一股 | CH-3/4/5/7 | 实战经验丰富，军贸出口 | 国企效率，估值 |
| 中无人机 | 688297 | 翼龙系列 | 翼龙-1/2 | 军用大型无人机 | 客户单一(军方) |
| 航天电子 | 600879 | 无人机配套 | 测控/通信 | 国企核心配套 | 增速慢 |
| 航宇微 | 300053 | 遥感载荷+AI | 高光谱载荷 | AI+载荷一体化 | 商业化慢 |

### 无人机供应链vs星链供应链的差异

| 维度 | 星链供应链 | 无人机供应链 |
|------|----------|------------|
| 市场阶段 | 刚起步（1000万→3000万） | 成熟（军贸稳定增长） |
| 增长驱动 | 商业+军事 | 主要靠军事+低空经济 |
| 估值 | 较高（已炒过一波） | 较低（军工估值体系） |
| 地缘风险 | 中（中美都有标的） | 高（军工敏感） |
| 信息透明度 | 中（SpaceX IPO后改善） | 低（军品保密） |

### 建议

1. **航天彩虹(002389)** 值得深入研究——CH-7隐身无人机2025年12月首飞，彩虹VH1000重载11.2吨，技术代差在追赶美国。
2. **但军工股的投资逻辑跟商业股不同**——更看重订单周期、军费预算、地缘政治，而不是PE/ROE。
3. **如果要配置无人机，建议先研究军工ETF**，再选个股。

## 七、风险提示

1. **地缘政治风险**: 中美对抗升级可能导致供应链断裂
2. **估值泡沫**: SpaceX高估值可能传导到整个航天板块
3. **技术风险**: 星舰/星链技术可能失败
4. **政策风险**: 中国军工股受政策影响大
5. **流动性风险**: 部分标的流动性差（A股小盘股）
6. **概念炒作**: A股"SpaceX概念股"可能被过度炒作
