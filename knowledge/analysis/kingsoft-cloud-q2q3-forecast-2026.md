# 金山云 2026年Q2/Q3 营收预测（修正版）

## 修正后的核心假设

```
基础增速: +30-35% (基于Q1实际, 原假设+15%)
MIMO时间线:
  3月: v2匿名发布 → 用户积累
  4月: 免费使用 → 调用量爆发(不产生收入)
  5月: 降价 → 开始计费
  6月: 完整付费月
→ Q2内MIMO产生收入: 5月+6月 = 2个月
→ Q3: 完整季度MIMO影响
```

## 修正后预测

### Q2 2026

```
基础 (不含MIMO):
├─ Q2 2025 = ¥22.5亿
├─ 按+30%增速: ¥29.3亿
├─ 按+35%增速: ¥30.4亿
└─ 合理区间: ¥29-30亿

MIMO贡献 (5-6月):
├─ 4月免费期积累的用户在5月转付费
├─ 5月: 部分月(降价后逐步起量)
├─ 6月: 完整月
└─ 贡献估算: ¥1-3亿

Q2总预测:
├─ 保守: ¥30亿 (基础¥29 + MIMO¥1)
├─ 基准: ¥31亿 (基础¥29.5 + MIMO¥1.5)
├─ 乐观: ¥33亿 (基础¥30 + MIMO¥3)
└─ YoY: +33% ~ +47%
```

### Q3 2026

```
基础 (不含MIMO):
├─ Q3 2025 = ¥24.0亿
├─ 按+30%增速: ¥31.2亿
├─ 按+35%增速: ¥32.4亿
└─ 合理区间: ¥31-32亿

MIMO贡献 (完整季度):
├─ 7-9月完整计费
├─ 4月免费用户惯性 + 5-6月新付费用户
├─ 用户基数持续扩大
└─ 贡献估算: ¥4-8亿

Q3总预测:
├─ 保守: ¥35亿 (基础¥31 + MIMO¥4)
├─ 基准: ¥37亿 (基础¥32 + MIMO¥5)
├─ 乐观: ¥40亿 (基础¥32 + MIMO¥8)
└─ YoY: +46% ~ +67%
```
