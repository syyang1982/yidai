# 观察清单：领先指标与催化剂分析 (2026年6月)

> **核心方法论**：PE是滞后指标。对周期股/成长股来说，等PE降到位可能已经错过最佳入场点，或是价值陷阱。应监控市场、营运、客户等**提前反应的指标**。
>
> 用户案例：中创新航的机会在于其它上游大客户的导入（如小米），而非等PE降到某个数字。

---

## 1. 中创新航 (03931.HK)

### PE陷阱警示
中创新航2025年净利大增148%，但这是**滞后结果**。如果等到PE降到"便宜"才买，可能已经错过了从小米/理想等客户导入带来的营收爆发期。电池行业产能过剩时PE看起来很便宜，但可能是价值陷阱——产能利用率低、价格战导致利润被压缩。

### 领先指标
1. **新客户导入进度**：已确认进入小米汽车供应链，为小米第二品牌"寻天"的"昆仑"车型一供（占40%配额），2026年中开始批量交付。同时推进小鹏MONA、智界/尚界、零跑等新平台。
2. **前五大客户集中度**：从2023年的71%降至2025年的51%，客户结构持续优化，议价权提升。
3. **800V高压平台5C超充电池月销量**：已超2万套，关注环比增速。
4. **产能利用率**：山东枣庄投资近百亿、产能达100GWh，关注实际投产节奏vs规划。
5. **固态电池进展**：60Ah固态电池已发布（450Wh/kg），2026年Q4交付人形机器人/eVTOL用电池。

### 催化剂时间线
| 时间 | 事件 |
|------|------|
| 2026年中 | 小米"昆仑"车型混动电池批量交付开始 |
| 2026年H2 | 小鹏MONA、零跑等新平台陆续量产 |
| 2026年Q4 | 450Wh/kg固态电池首次交付（机器人/eVTOL） |
| 2027年 | 固态电池小批量汽车集成 |
| 持续 | 丰田、大众、现代等海外车企交付量攀升 |

### 入场信号
- 小米"昆仑"车型预售数据超预期，确认中创新航电池出货量级
- 月度装机量排名连续提升（从第三向第二逼近）
- 固态电池客户验证通过的公告
- 产能利用率从低位回升至70%+的季度数据

### 风险信号
- 小米汽车销量不及预期或"寻天"品牌推迟
- 电池价格战加剧，毛利率持续下行
- 产能扩张过快但利用率持续低迷（<50%）
- 大客户再次集中化（前五大客户依赖度回升）

## 2. 来福谐波 (301528.SZ)

### PE陷阱警示
来福谐波目前仍处于亏损状态，传统PE无意义。但即使未来盈利，PE也不能反映其核心价值——**人形机器人赛道的爆发性**。谐波减速器是机器人关节核心部件，市场增长曲线是指数级的（2025年1.5万台→2030年110万台，CAGR 133.8%），PE会滞后于订单爆发。

### 领先指标
1. **销量增速**：2026年前4个月销量13.39万台，同比激增114.2%（去年同期6.25万台）。全年累计销量已突破100万台。
2. **人形机器人客户进展**：已实现人形机器人用谐波减速器交付并进入量产，是国内仅有的两家之一。头部客户已进入小批量试生产阶段。
3. **下游客户名单**：新松机器人、埃斯顿、优必选等，关注新增头部机器人厂商导入。
4. **市场份额变化**：2025年中国谐波减速器市场排名第二（21.4%），关注vs绿的谐波的份额变化。
5. **港股IPO进展**：2026年6月公开招股书，关注融资用途和产能扩张计划。

### 催化剂时间线
| 时间 | 事件 |
|------|------|
| 2026年6月 | 港交所招股书公开 |
| 2026年H2 | 人形机器人头部客户量产验证结果 |
| 2026-2027 | 全球人形机器人出货量从1.5万台向10万台跃迁 |
| 持续 | 关节模组/机械臂产品线拓展 |

### 入场信号
- 人形机器人头部客户（如特斯拉Optimus、Figure等）明确采购订单
- 单季度销量突破10万台且同比增速维持100%+
- 产能扩建公告，说明需求已经溢出
- 港股IPO获得超额认购，机构认可度高

### 风险信号
- 人形机器人商业化节奏低于预期（量产推迟到2028+）
- 绿的谐波降价抢份额，毛利率持续承压
- 客户集中度过高（依赖单一大客户）
- 亏损持续扩大，现金流恶化

## 3. 英维克 (002837.SZ)

### PE陷阱警示
英维克2025年前三季度营收增长40%，但PE可能看起来偏高。然而液冷行业正处于**从叙事到订单兑现的关键转折点**。如果等PE降到合理区间，可能错过了2026年订单集中释放的窗口。部分液冷订单已排到2026年，行业增长是爆发式的。

### 领先指标
1. **液冷订单量/增速**：液冷业务增速超80%，液冷机柜交付量年增200%，整体订单年增50%。部分订单已排到2026年。
2. **超大规模客户签约**：据报道正与谷歌洽谈采购数据中心液冷系统。关注字节、阿里等国内大厂签约进展。
3. **GB300适配认证**：已适配英伟达GB300液冷板，通过Intel认证。关注与NVIDIA下一代产品的同步开发。
4. **单柜功率密度**：已实现单柜200kW批量交付，关注更高功率密度产品的研发进展。
5. **行业渗透率**：2026年全球AI服务器液冷市场规模预计从89亿→170亿美元（接近翻倍）。

### 催化剂时间线
| 时间 | 事件 |
|------|------|
| 2026年全年 | 液冷订单集中交付，公司预计"2026年增速会加快" |
| 2026年 | 全球AI服务器液冷市场翻倍至170亿美元 |
| 2026年H2 | GB300服务器量产带动液冷需求爆发 |
| 2027年 | 国内液冷市场超400亿元 |

### 入场信号
- 单季度液冷订单同比增长100%+的财报数据
- 与谷歌/微软/字节等超大规模客户签订框架协议公告
- GB300量产后液冷需求确认的行业数据
- 新产品（更高功率密度液冷方案）发布

### 风险信号
- 液冷渗透率不及预期，风冷仍是主流
- 竞争加剧，价格战压缩毛利率
- 超大规模客户自研液冷方案（绕过第三方供应商）
- AI算力投资放缓导致数据中心建设延迟

## 4. 海光信息 (688041.SH)

### PE陷阱警示
海光信息PE极高（信创+AI双概念），但这是典型的**国产替代赛道**——需求由政策和国家安全驱动，不受经济周期影响。等PE降到合理区间，可能意味着国产替代已经完成、增长放缓。关键是监控**DCU出货量和客户渗透率**，而非PE。

### 领先指标
1. **DCU出货量/市占率**：2025年国产AI芯片品牌出货份额已达30%，海光位列前列。关注每季度出货量环比变化。
2. **政府/国企采购订单**：信创采购是核心驱动力，关注央企、金融、电信等行业采购节奏。
3. **CUDA兼容性优势**：DCU算子覆盖度超99%，迁移效率损失低于ASIC方案。关注开发者生态活跃度。
4. **产品迭代节奏**："深算三号"已商用，"深算四号"研发中。关注下一代产品性能提升幅度。
5. **营收增速**：2025年Q1同比增68%，H1增45.2%。关注增速是否维持或加速。

### 催化剂时间线
| 时间 | 事件 |
|------|------|
| 2026年 | "深算四号"研发进展/流片消息 |
| 2026年 | 信创第三批/第四批集采落地 |
| 持续 | 国产AI芯片市占率从30%向50%提升 |
| 持续 | 中美科技博弈升级→国产替代加速 |

### 入场信号
- DCU季度出货量环比增长加速（而非减速）
- 新一轮信创集采中海光份额提升
- "深算四号"性能大幅提升的公告
- 中美科技制裁升级→国产替代紧迫性增加

### 风险信号
- 华为昇腾份额快速挤压海光（竞争格局恶化）
- DCU性能迭代不及预期，与NVIDIA差距拉大
- 信创采购节奏放缓（预算削减）
- 美国制裁升级导致EDA/代工受限

## 5. 海康威视 (002415.SZ)

### PE陷阱警示
海康威视PE已经回落到较低水平，看起来"便宜"。但安防行业是典型的周期+政策驱动行业，PE低可能是**海外制裁长期化、国内政企需求疲软**的反映。等PE再降可能是价值陷阱。应关注**海外恢复趋势和AI业务占比**作为拐点信号。

### 领先指标
1. **海外营收增速**：2025年海外主营收入272亿元，占比29.4%。2020-2024年海外营收从177亿增至319亿。关注新兴市场增长是否持续。
2. **创新业务占比**：海康存储、海康微影、海康机器人预计高速增长。关注创新业务营收占比变化。
3. **AI解决方案占比**：从"卖硬件"到"卖解决方案"的转型进度。关注AI相关收入增速。
4. **政企订单回暖**：国内主业营收2025年下滑4.2%，关注2026年是否企稳回升。
5. **毛利率变化**：海外毛利率47.26%（2025H1），高于整体。关注海外占比提升对整体毛利率的拉动。

### 催化剂时间线
| 时间 | 事件 |

| 2026年Q1 | 已确认：营收+11.78%，净利+36.42%，经营拐点初现 |
| 2026年 | 创新业务（机器人/存储/微影）高速增长验证 |
| 持续 | 海外"一国一策"本地化战略深化 |
| 持续 | 观澜大模型与机器人业务融合→效率提升30%+ |

### 入场信号
- 连续2个季度海外营收增速>15%，确认恢复趋势
- 创新业务营收占比突破20%
- 国内政企订单同比转正（从-4%到正增长）
- AI解决方案签约金额大幅增长

### 风险信号
- 海外制裁范围扩大（更多国家限制采购）
- 国内安防市场持续萎缩，价格战加剧
- 创新业务投入大但回报低于预期
- 管理层持续减持

## 6. 万国数据 (09698.HK)

### PE陷阱警示
万国数据处于重资产扩张期，净利润可能为负或很低，传统PE无意义。关键是监控**新签订单量和上架率**——这是未来营收的领先指标。订单量创新高但上架率低迷，意味着短期投入大、回报滞后，PE可能长期为负。

### 领先指标
1. **新签订单量**：2026年Q1新签200MW创季度纪录，截至5月已超340MW，积压订单近600MW。全年目标>500MW，60-70%来自AI。
2. **AI客户占比**：关注AI相关收入占比变化，从传统IDC向AI数据中心转型的进度。
3. **上架率/投产面积**：2026年投产面积超10万㎡，2027年翻倍。关注上架率是否同步提升。
4. **海外扩张**：马来西亚柔佛州数据中心二期投运，关注海外订单贡献。
5. **资本效率**：2026年Capex约90亿元，关注每MW投资回报率变化。

### 催化剂时间线
| 时间 | 事件 |
|------|------|
| 2026年全年 | 新签订单目标>500MW，已锁定340MW+ |
| 2026年 | 3亿美元可转债融资到位，加速扩张 |
| 2026-2027 | 新签订单12-18个月后转化为计费收入 |
| 2027年 | 投产面积翻倍，收入加速增长 |

### 入场信号
- 单季度新签订单突破200MW且AI占比>60%
- 上架率持续提升（从低位向70%+攀升）
- 海外市场获得超大规模客户订单
- 资产货币化交易落地（降低资本压力）

### 风险信号
- 新签订单增速放缓（AI需求低于预期）
- 上架率持续低迷，重资产拖累现金流
- 资本支出失控，杠杆率持续攀升
- 数据中心供给过剩导致租金下行

3. **库存增长**：机构认为库存增长信号充足订单。关注存货周转天数变化。
4. **客户拓展**：持续新增云服务商客户，订单生产排期"非常紧凑"。
5. **高速网络业务**：800G产品为2025-2026主力，1.6T交换机/CPO/ASIC陆续推出。

| 2027年 | 1.6T交换机/CPO商业化 |

## 9. 永辉超市 (601933.SH)

### PE陷阱警示
永辉超市五年累亏超百亿，PE为负或无意义。即使未来扭亏，零售行业的PE也不能反映**改造效果的持续性**。关键是监控**同店增长趋势和改造门店盈利的可持续性**——短期促销带来的客流增长≠长期经营改善。

### 领先指标
1. **同店客流与销售增长**：CEO确认"同店客流与销售实现双增长"。关注每个季度的同店增长率变化。
2. **改造门店盈利持续性**：通州万达店开业4天销售700万、客流+200%，但关键是3-6个月后是否持续。
3. **生鲜占比提升**：标杆门店生鲜占比从5%→20%，上新商品占比>26%。关注整体毛利率变化。
4. **关店节奏**：2025年关闭近400家低效门店。关注2026年关店速度是否放缓（说明存量门店质量提升）。
5. **员工成本**：工资平均涨幅超30%+缩短工时。短期增加成本，长期应提升服务质量→复购率。

### 催化剂时间线
| 时间 | 事件 |
|------|------|
| 2026年3月 | "胖改"进入第二阶段"精细化深耕" |
| 2026年Q2-Q3 | 关注同店增长是否维持正增长 |
| 2027年6月前 | 公司目标实现"健康经营" |
| 持续 | 供应链改革与自有品牌建设 |

### 入场信号
- 连续2-3个季度同店增长>5%（非开业期促销驱动）
- 改造门店6个月后利润率>改造前
- 关店速度放缓+新开店数量回升
- 自有品牌占比提升带动毛利率改善

### 风险信号
- 同店增长昙花一现（开业期火爆但3个月后回落）
- 员工成本上升但服务质量/复购率未提升
- 持续亏损扩大（五年累亏超百亿的惯性）
- 行业竞争加剧（社区团购/折扣店分流）

## 10. 铖昌科技 (001270.SZ)

### PE陷阱警示
铖昌科技2025年刚扭亏为盈（营收4.5亿+90%，净利1.17亿+470%），PE可能看起来很高。但卫星互联网T/R芯片是**政策驱动的万亿级赛道**，PE不能反映中国星网等大规模组网带来的订单爆发。关键是监控**卫星发射节奏和T/R芯片订单量**。

### 领先指标
1. **中国星网卫星发射节奏**：星网是核心驱动力，关注每月/每季度发射数量。
2. **T/R芯片订单量**：下游客户为中国电科、航天科技、航天科工等总体单位。关注订单金额变化。
3. **摘帽进展**：2026年5月20日已完成摘星脱帽，涨跌幅恢复10%。关注摘帽后机构持仓变化。
4. **商业航天政策**：商业航天被视为万亿级市场，关注国家政策/资金支持力度。
5. **客户集中度风险**：客户集中度高、现金流承压。关注客户多元化进展。

### 催化剂时间线
| 时间 | 事件 |
|------|------|
| 2026年5月 | 已完成摘星脱帽 ✅ |
| 2026年 | 中国星网加速组网→T/R芯片需求爆发 |
| 2026-2027 | 商业航天政策持续加码 |
| 持续 | 卫星互联网从试验组网到规模商用 |

### 入场信号
- 中国星网月度发射数量加速（从个位数到两位数）
- 公司公告T/R芯片订单大幅增长（金额同比>100%）
- 摘帽后机构资金回流，北向资金增持
- 商业航天获国家级政策/资金支持

### 风险信号
- 星网发射节奏低于预期（预算/技术问题）
- 竞争对手（如国博电子等）抢占份额
- 客户集中度过高导致现金流脆弱
- 摘帽后股价已充分反映预期（利好出尽）

## 总结：方法论框架

### 不要只看PE，要看这些领先指标

| 指标类型 | 具体指标 | 适用公司 |
|----------|----------|----------|
| **客户导入** | 新大客户确认/订单量 | 中创新航、来福谐波、英维克、海光 |
| **出货量/产能利用率** | 月度/季度出货量增速 | 工业富联、中际旭创、来福谐波 |
| **新签订单/预订量** | MW/金额/合同 | 万国数据、英维克 |
| **同店/经营趋势** | 同店增长、毛利率 | 永辉超市 |
| **政策/行业节奏** | 发射数量、采购周期 | 海光信息、铖昌科技 |
| **海外恢复** | 海外营收占比/增速 | 海康威视 |
| **产品迭代** | 新产品出货/认证 | 中际旭创、工业富联 |

### 核心原则
1. **领先指标先行**：客户导入→订单增长→营收增长→利润增长→PE下降。在第一步就行动。
2. **催化剂驱动**：每个公司都有具体的时间窗口，不要等"便宜"再买，要等"催化剂确认"再买。
3. **风险信号同样重要**：即使PE很便宜，如果领先指标恶化（客户流失、订单下滑、政策转向），也不应该买入。
